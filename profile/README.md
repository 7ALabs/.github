# 7Agents

A 7Agents desenvolve produtos próprios de software. O trabalho é orientado por qualidade, simplicidade e evolução contínua: poucos produtos, construídos com cuidado e mantidos ao longo do tempo.

## Produto principal

### SignallQ

O SignallQ é uma plataforma para diagnóstico de conectividade, desenvolvida para ajudar usuários a compreenderem melhor a qualidade de suas conexões de rede. Coleta métricas de sinal, throughput e estabilidade e as traduz em um diagnóstico claro.

Status atual:

- Android — Em desenvolvimento
- Web App (PWA) — Em desenvolvimento
- iOS — Planejado
